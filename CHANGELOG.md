# Changelog

All notable changes to MasqueRole. The project follows [Semantic Versioning](https://semver.org).
This file lists only the current and the previous version.

## [0.10.7] - 2026-11-02

### Fixed

- **Provider drop-down:** every row of the list is one button as wide as the list, so a click on the logo, the name or the empty space beside them chooses the provider. Before, only the text could be clicked.

## [0.10.6] - 2026-11-02

### Added

- **Provider logos:** the provider drop-down on the provider page shows the logo of OpenAI, Anthropic and Ollama before the name, in the list and in the closed field. Providers without a logo file get a small colored letter mark.
