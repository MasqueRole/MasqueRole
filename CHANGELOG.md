# Changelog

All notable changes to MasqueRole. The project follows [Semantic Versioning](https://semver.org).
This file lists only the current and the previous version.

## [0.10.2] - 2026-11-02

### Fixed

- **Light mode:** a small black piece no longer shows behind the rounded top left corner of the page.

## [0.10.1] - 2026-11-02

### Changed

- **Story info page:** the page now sits directly on the content area instead of in cards. The world's picture is the backdrop of the page and fades into the background.
- **Characters:** the characters of a story are a list of picture, name and a remove button, below a small "Characters" title. Removing a character keeps its earlier messages.
