# Changelog

All notable changes to MasqueRole. The project follows [Semantic Versioning](https://semver.org).
This file lists only the current and the previous version.

## [0.10.5] - 2026-11-02

### Changed

- **Provider page:** the page now sits flat on the content area with one title, without a card around the fields.
- **Settings:** the Provider tab is gone from the settings window, since the provider has its own page in the rail.

## [0.10.4] - 2026-11-02

### Added

- **Provider page:** a plug icon in the rail opens the provider, endpoint, model and API key right in the content area, so changing the provider no longer takes a detour through the settings. Save is in the footer. The settings screen still has the same fields on its Provider tab.
